# Decisions

One row per decision. "Settled" means the code follows it; a change needs a pull request that states the size of the effect and its physical cause. Sources: the project briefing, `LDPM_Repo_Roadmap.md`, the stage-interface doc (v2), and the threads cited.

Tags: **measured** = output of a run (which code is named), **derived** = hand calculation, **printed** = value in a paper or source file.

| ID | Question | Decision | Status |
|---|---|---|---|
| D1 | One lattice element per Delaunay edge, or one per facet (12 per tet)? | **Per edge by default** (Fascetti 2018, Eq. 22; the flat CPU solver and Paper 1). Per facet becomes an option at stage 3. Both use the same flat kernels; only the facet builder, the ε_V mapping and the ζ_e copy differ. | Settled 2026-10-14 (Hasan); advisor to confirm |
| D2 | Volumetric strain: (V − V₀)/V₀ area-weighted (Fascetti 2018, Eqs. 22–23) or ΔV/(3V₀) per tet (Pathirage 2023, App. A.1)? | Option, default Fascetti (FAITHFUL-NOTE). Under pure hydrostatic strain ε the first gives e_D = −2ε, the second 0 (derived); K_c, k_c1, k_c2 were identified with the first. | Proposed |
| D3 | Density | ρ = 2.5e-9 t/mm³. The legacy 2.5e-6 is kg/mm³, so every ω is √1000 = 31.6× too low (derived). Fix at stage 4, in one PR with the Δt policy, the mass-scaling threshold (ω > 2/Δt) and ω_PATHOLOGICAL = 1e9. Print the added-mass ratio. **Linked:** `TetrahedronStiffnessMatrix` builds K_edge = BᵀDB without A_f/ℓ, which gives ω² units of 1/(mm·s²) (Tetrahedra-tracing thread, 2026-10-14). Fix both together, or the frequency check stays wrong after the density fix. | Settled as fact; code at stage 4 |
| D4 | Delaunay library | **TetGen**, switch "Q", for every geometry. It is needed for STL shapes; one triangulator means one set of degeneracies. MiniQhull's default flags gave flat tets in the static solver (static-solver thread). Baixi's static solver must read `mesh_tets.csv` or call TetGen, or static-vs-explicit comparisons are not on the same mesh. TetGen is AGPLv3 (see D8). | Settled 2026-10-14 |
| D5 | Porosity at placement (Fascetti 2022 §6.1 rejects aggregates that overlap pores) | `pore_check = sphere \| centroid`, **required** whenever porosity is on, no default. `sphere` is a box–sphere test on the SCRF's own voxel size and origin. `centroid` prints the measured overlap fraction. The project's `Random_Meshing_Porosity.jl` runs a full-sphere voxel-centre test, while briefing §12 says centroid-only; reconcile when the porosity code is flattened. | Settled; code deferred |
| D6 | ζ_e per element | Copy the edge value (Fascetti 2022, Eq. 22). With D1 per edge, the mapping is one-to-one. | Settled by D1 |
| D7 | Canonical names | Stages 1–2: `docs/NAMES.md`. Later stages: open. | Partly settled |
| D8 | Licence and release | UCF disclosure (Reg. 2.033), Pitt release for the JuLDPM name and the arc-length code, licence choice. TetGen's AGPL affects the licence. | Open |
| D9 | Wall rule (minimum aggregate-centre distance to the surface) | Named option `wall_rule`: `pc_half_d` (r = pc·d/2; `Random_Meshing_New_Boundary.jl`, v4 STL tree) or `ceil_half_d` (r = ceil(d/2); `Random_Meshing_Porosity.jl`). Inputs use `pc_half_d`. The legacy trees gave peaks of ~37 and ~35 MPa (measured, legacy runs). | Settled |
| D10 | Random numbers | `StableRNG(seed)`; `seed = 0` draws a new seed from the OS and prints it. The seed is written to `mesh_nodes.csv`. Gate: the same seed reproduces the nodes bit for bit, seed + 1 changes them. | Settled |
| D11 | Surface nodes | Corners, feature chains at equal spacing, Poisson-disk faces, for the box too, instead of the legacy regular face grid. The grid's cocircular squares give exactly flat tets (143–153 per realization on 50×50×100; Qhull diagnostic, roadmap D4). Python mirror, 75×75×150 box: **0 flat tets**. **Density differs:** h_surf = 10 gives ~390 surface nodes against 520 for the legacy 8×8×16 grid (−25 %), and 54–59 against 64 on the loaded face; h_surf = 8.6 gives ~512 (measured, Python mirror, 3 seeds). **Open:** which h_surf to use when comparing with Paper 1. | Settled; h_surf open |
| D12 | Input files | `key = value  # comment`; an unknown or repeated key is an error. Replaces row-numbered files. | Settled |
| D13 | Loaded area on curved specimens | The platen loads the mesh's face, i.e. the polygon of the surface nodes, not the STL face. Cylinder D75, h_surf = 10: cap mesh area / STL area = 0.9887, a 1.13 % deficit with 24 rim nodes (measured, Python mirror; derived (2π/24)²/6 = 1.14 %). Stage 5 should take A_load from `Patch_Area_Mesh` (Gate_Delaunay), or rim spacing should be refined. | Open (stage 5, Radia) |
| D14 | Surface spacing on concave curved surfaces | A chord between surface nodes h apart on a concave surface of radius R leaves the surface by h/(8R) of its length (derived). Above excursion_tol = 0.05 it is treated as void-bridging and its tets are removed, leaving holes. So h_surf < 0.4 R. Tube with r_i = 20 mm (Python mirror): h_surf = 10 left 145 tets (2.1 % of V) as holes; h_surf = 7 conformed (χ = 0, no holes). `Gate_Delaunay` now fails on any removed material. Automatic curvature-based spacing is possible (local R from adjacent facet normals) but is not built. | Settled (rule); automatic spacing open |
